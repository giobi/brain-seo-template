# Technical SEO

This folder contains technical audits, site health monitoring, and optimization recommendations.

## What Goes Here

- Technical SEO audits
- Page speed analysis
- Crawl error reports
- Schema markup documentation
- Mobile optimization notes
- Core Web Vitals tracking
- Indexing issues
- XML sitemap documentation

## File Naming

Use audit type and date:
- `2025-11-site-audit.md`
- `page-speed-optimization.md`
- `schema-implementation-guide.md`
- `mobile-issues-2025-q4.md`

## Template Structure

See [example-technical-audit.md](example-technical-audit.md) for a ready-to-use template.

## Tips

- Run audits quarterly (at minimum)
- Track fixes with Git commits
- Prioritize issues by impact (high/medium/low)
- Document recurring issues
- Link to implementation guides

## AI Prompt Examples

**To create audit:**
```
"Create a technical SEO audit report in technical/ for example.com including crawl errors, page speed, mobile issues, and schema opportunities"
```

**To prioritize fixes:**
```
"Read technical/[audit-file] and create a prioritized action plan with high-impact fixes first"
```

**To track progress:**
```
"Compare technical audits from last 3 months and summarize improvements and remaining issues"
```
