# Content

This folder contains blog posts, landing pages, content briefs, and editorial calendars.

## What Goes Here

- Published blog posts
- Content briefs and outlines
- Landing page copy
- Editorial calendars
- Content performance analysis
- Content ideas and brainstorms

## Folder Organization

You can organize by:
- **Status:** `drafts/`, `published/`, `updated/`
- **Type:** `blog/`, `landing-pages/`, `product-pages/`
- **Date:** `2025-11/`, `2025-12/`

Or keep it flat (recommended for small projects).

## File Naming

Use descriptive names with dates:
- `2025-11-21-sustainable-fashion-guide.md`
- `landing-page-eco-clothing.md`
- `content-brief-fashion-trends.md`

## Template Structure

See [example-blog-post.md](example-blog-post.md) for a ready-to-use template.

## Tips

- Include target keyword in frontmatter
- Link to related keyword research in `keywords/`
- Track publication date and last update
- Note target word count and actual word count
- Include meta description and title tag

## AI Prompt Examples

**To create content brief:**
```
"Create a content brief in content/ for a blog post targeting 'sustainable fashion tips' with outline, target keywords, and competitor analysis"
```

**To draft blog post:**
```
"Write a 1500-word blog post in content/ based on brief [filename] with SEO-optimized headings and internal linking suggestions"
```

**To update existing content:**
```
"Read content/[filename] and suggest 5 improvements to increase search rankings"
```
