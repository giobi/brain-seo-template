# Keywords

This folder contains keyword research, analysis, and grouping for your SEO projects.

## What Goes Here

- Keyword research reports
- Search volume analysis
- Keyword difficulty scoring
- Keyword clustering and grouping
- Competitor keyword gaps
- Long-tail keyword opportunities

## File Naming

Use descriptive names with topic/niche:
- `sustainable-fashion-keywords.md`
- `2025-11-ecommerce-keywords.md`
- `competitor-gap-analysis.md`

## Template Structure

See [example-keyword-research.md](example-keyword-research.md) for a ready-to-use template.

## Tips

- Use tables for easy scanning
- Include search volume, difficulty, intent
- Tag keywords by funnel stage (awareness, consideration, decision)
- Link to related content in `content/` folder
- Update regularly as search trends change

## AI Prompt Examples

**To create keyword research:**
```
"Create a keyword research file in keywords/ for [topic] with 20 keywords including search volume, difficulty, and search intent"
```

**To analyze existing keywords:**
```
"Read keywords/*.md and identify the top 5 opportunities with high volume and low difficulty"
```

**To find gaps:**
```
"Compare keywords in keywords/ with competitors in competitors/ and identify missing opportunities"
```
