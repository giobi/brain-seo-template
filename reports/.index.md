# Reports

This folder contains performance reports, analytics summaries, and progress tracking.

## What Goes Here

- Monthly/weekly SEO reports
- Traffic analysis
- Ranking reports
- Conversion tracking
- Client reports (if agency)
- Year-over-year comparisons
- Goal tracking

## File Naming

Use date format:
- `2025-11-monthly-report.md`
- `2025-q4-quarterly-report.md`
- `2025-annual-review.md`

## Template Structure

See [example-monthly-report.md](example-monthly-report.md) for a ready-to-use template.

## Tips

- Keep reports consistent (use same metrics monthly)
- Highlight wins and areas for improvement
- Include actionable insights, not just data
- Track progress toward goals
- Visualize data when possible (tables, charts)

## AI Prompt Examples

**To create report:**
```
"Create a monthly SEO report in reports/ for November 2025 with traffic, rankings, and top pages"
```

**To analyze trends:**
```
"Compare last 3 monthly reports in reports/ and identify trends and anomalies"
```

**To generate insights:**
```
"Read reports/2025-11-monthly-report.md and suggest 3 high-impact optimizations for December"
```
