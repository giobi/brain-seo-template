# Projects

This folder contains client-specific or site-specific SEO projects.

## What Goes Here

- Client project folders (if agency)
- Site-specific campaigns
- Niche-specific strategies
- Multi-site management

## Folder Organization

Each project gets its own subfolder:

```
projects/
├── client-a/
│   ├── index.md (project overview)
│   ├── keywords/
│   ├── content/
│   └── reports/
├── client-b/
│   ├── index.md
│   └── ...
└── my-side-project/
    ├── index.md
    └── ...
```

## File Naming

Use client or site name:
- `projects/acme-corp/`
- `projects/my-ecommerce-site/`
- `projects/blog-relaunch/`

## Template Structure

See [example-client-project/](example-client-project/) for a ready-to-use template.

## Tips

- Keep all project files in one folder
- Link to shared resources in root folders (keywords, backlinks)
- Document project goals and KPIs in `index.md`
- Track progress with Git commits
- Archive completed projects
