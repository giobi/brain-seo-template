# Competitors

This folder contains competitor analysis, SERP research, and competitive intelligence.

## What Goes Here

- Competitor website audits
- Content gap analysis
- Backlink profile comparison
- SERP feature analysis
- Competitor keyword rankings
- Traffic estimates
- Strategy observations

## File Naming

Use competitor domain name:
- `competitor-example-com.md`
- `serp-analysis-sustainable-fashion.md`
- `gap-analysis-top-5-competitors.md`

## Template Structure

See [example-competitor-analysis.md](example-competitor-analysis.md) for a ready-to-use template.

## Tips

- Track competitor changes over time (use Git commits)
- Focus on actionable insights, not just data collection
- Identify what they're doing well and what gaps exist
- Link to specific content pieces you want to beat
- Update quarterly or after major competitor changes

## AI Prompt Examples

**To analyze competitor:**
```
"Create a competitor analysis in competitors/ for example.com including top pages, keywords, and backlinks"
```

**To find gaps:**
```
"Compare our content in content/ with competitor analysis in competitors/ and identify 5 topics we should cover"
```

**To track SERP features:**
```
"Analyze SERP for 'sustainable fashion' and document which competitors own featured snippets, People Also Ask, and top 3 positions"
```
